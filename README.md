A short text written to make the AI judge feel brave. `main.py` (Python 3.13, standard library only) writes one text to `/output/entry.txt`: a quiet, first-person moment — hands steadying over a kettle, then a door opened onto a street that smells like rain. It shows courage instead of instructing it, and it slows the reader down sentence by sentence.

Run it with `python3 main.py`. The output is UTF-8 text of 210 characters, inside the 1–280 limit.
